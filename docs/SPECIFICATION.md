# 家計簿アプリ (kakeibo-app) 仕様書

## 1. 概要
本プロジェクトは、Base44で運用していた家計簿アプリの優れたUXと機能を継承し、**React + Vite + TypeScript + Tailwind CSS** で構築された完全独立型のモダンWebアプリケーションです。
将来的にSupabaseへの接続を想定しつつ、まずはローカル状態管理（LocalStorage / IndexedDB）にて無料で自律動作し、スマートフォン・iPad・PCすべてのデバイスで快適に利用できるレスポンシブかつPWA対応の家計簿システムを提供します。

---

## 2. 開発・技術方針

| 項目 | 技術・ライブラリ | 選定理由・方針 |
| :--- | :--- | :--- |
| **フロントエンド** | React 18 / 19, TypeScript | 型安全性とコンポーネント指向による堅牢なUI開発 |
| **ビルドツール** | Vite | 高速なHMR（Hot Module Replacement）と最適化された本番ビルド |
| **ルーティング** | React Router (v6 / v7) | SPA（シングルページアプリケーション）の画面遷移・URL管理 |
| **スタイリング** | Tailwind CSS | ユーティリティファーストによる柔軟で高速なレスポンシブ＆ダークモード設計 |
| **グラフ・可視化** | Recharts | React親和性の高いSVGベースのインタラクティブチャート |
| **アイコン** | Lucide React | 軽量で統一感のあるモダンなアイコンセット |
| **日付処理** | 厳密なISO8601(YYYY-MM-DD)文字列 | タイムゾーン（UTC/JST）の解釈ズレによる日付ずれの完全防止 |
| **データ保存** | LocalStorage / 将来的にSupabase | オフラインファーストで即座に動作し、将来のクラウド同期にも対応 |
| **対応端末** | スマートフォン, iPad, Windows/Mac PC | モバイルファーストのボトムナビゲーションと大画面向けサイドバー |
| **セキュリティ** | 環境変数（`.env.example`）、個人データ分離 | APIキー直書きの禁止、取引CSVや個人情報をGitにコミットしない設計 |

## 3. 重要な設計方針・計算原則

1. **画面（UI）と計算ロジックの完全分離**
   - 残高計算、収支集計、資産推移計算は専用モジュール（`src/services/calculation/balanceEngine.ts`）に集約。
2. **取引履歴（Transactions）を中心とする台帳モデル**
   - 口座残高や月間収支は、開始残高（Opening Balance）と取引履歴から決定論的に算出。
3. **二重計上の完全防止**
   - **口座間移動（振替）**: 送金元口座の減額と送金先口座の増額を同一ペアとして記録。総資産の合計額には一切影響を与えない。
   - **クレジットカード**: カード利用時は利用日時点で「未払金（負債）」として計上し、引き落とし日に銀行口座から一度だけ引き落とす（二重計上しない）。
4. **整数円（Integer Yen）管理**
   - 金額はすべて正の整数（`number`, `Math.round`処理）として保持し、浮動小数点数の丸め誤差を防ぐ。
5. **日付ずれの防止**
   - 日付は `YYYY-MM-DD` 形式の文字列をプライマリキー・識別子とし、UTCタイムゾーン変換による日付逆戻りを防ぐ。

## 4. 画面一覧・機能要件

1. **ホーム画面 (`/`)**: 月間収支サマリー、資産ビュー（総資産/負債/純資産）、予算進捗、直近の取引・支出予定。
2. **取引履歴画面 (`/transactions`)**: 取引一覧表示、検索・絞り込み、取引削除・編集。
3. **分析画面 (`/analytics`)**: Rechartsによるカテゴリ別支出円グラフ、6ヶ月収支推移棒グラフ。
4. **口座・資産分析画面 (`/accounts`)**: 口座一覧と残高、純資産推移エリアチャート、新規口座追加。
5. **カレンダー画面 (`/calendar`)**: 月間カレンダー、日別収支バッジ、選択日の取引一覧。
6. **月間予算画面 (`/budgets`)**: 月間総予算の設定、カテゴリ別支出・予算消化率プログレスバー。
7. **貯金目標画面 (`/goals`)**: 貯金目標カード、達成率、期日までの残り日数、新規目標登録。
8. **設定画面 (`/settings`)**: カラーテーマ（ライト/ダーク/端末連動）、CSVエクスポート・インポート、サンプルデータリセット、Supabase接続状態。
